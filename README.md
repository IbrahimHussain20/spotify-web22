# Spotify Android

A native Android Spotify application built with Kotlin and Jetpack Compose, rewritten from the web version while preserving all core features, dark theme aesthetics, and playback logic.

## Features
- **Curated Music Catalog**: Full 40-song library spanning pop, rock, electronic, and hip-hop hits with high-resolution album artwork.
- **Audio Playback Engine**: Integrated player powered by the YouTube IFrame API bridge supporting streaming, seeking, volume controls, mute, shuffle, and repeat modes (Off, All, One).
- **Now Playing & Full-Screen Player**: Bottom mini-player docked above navigation, expandable into an immersive full-screen player with live scrub bar, volume slider, queue viewer, and track options.
- **Live Search & Browse**: Live debounced search across the catalog with support for optional YouTube Data API v3 key integration, plus vibrant genre browse categories.
- **Your Library & Playlists**: Persistent Liked Songs collection and custom user playlists (create, add songs, remove songs, delete playlists).
- **Material 3 Spotify Design**: Signature dark surfaces (`#121212`, `#181818`), Spotify green accents (`#1DB954`), responsive navigation, and adaptive launcher icon.
